## Descripción del Proyecto

Este proyecto consiste en el desarrollo de una página web única y responsiva utilizando el framework Bootstrap 5. 

La página integra cinco secciones temáticas y aplica conceptos clave como el sistema de grid, componentes interactivos, alineación mediante utilidades y diseño responsivo.

El objetivo principal es demostrar el dominio del desarrollo frontend utilizando Bootstrap, aplicando buenas prácticas de organización y estructura semántica.

---

## Objetivos a Implementar

- Uso del sistema de grid de Bootstrap
- Implementación de breakpoints para garantizar responsividad
- Integración de múltiples componentes interactivos
- Aplicación de utilidades de alineación horizontal y vertical
- Organización semántica del contenido


---

## Tecnologías Utilizadas

- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
